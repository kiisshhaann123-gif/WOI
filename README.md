# A World of Imagination

A first-person 3D portfolio universe built with Three.js. Walk through the Origin, the Art Museum, the Project Hall, the Retro Game Room, the Creative Playground and the Cabin.

**Controls**
- Desktop: WASD to move, mouse to look, E to interact, Esc for the menu
- Mobile: left thumb to move, right thumb to look, the E button to interact (landscape recommended)

Everything is a static site: open `index.html` through any web server, or enable GitHub Pages.
